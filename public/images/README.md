# Image assets

Drop image files here. They are served from the site root, so a file named
`becky-portrait.jpg` in this folder is referenced in code as `/images/becky-portrait.jpg`.

## Practitioner portrait

Save Becky's portrait as:

    public/images/becky-portrait.jpg

It is referenced from `src/lib/site.ts` (the `portrait` field). If you use a
different filename or format (e.g. `.png`, `.webp`), just update that field to
match. Recommended: a portrait-orientation photo, at least 1000px tall, under ~500KB.
